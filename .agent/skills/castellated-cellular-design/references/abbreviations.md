# Abbreviations

List of abbreviations used in AISC Design Guide 31 for Castellated and Cellular Beam Design.

## Design Standards and Organizations

| Abbreviation | Full Term | Description |
|--------------|-----------|-------------|
| **AISC** | American Institute of Steel Construction | Publisher of steel design standards and guides |
| **ANSI** | American National Standards Institute | Standards organization |
| **ASD** | Allowable Strength Design | Design method using service loads and safety factors (Ω) |
| **ASTM** | American Society for Testing and Materials | Materials standards organization |
| **AWS** | American Welding Society | Welding standards organization |
| **LRFD** | Load and Resistance Factor Design | Design method using factored loads and resistance factors (φ) |

## Beam Types and Nomenclature

| Abbreviation | Full Term | Description |
|--------------|-----------|-------------|
| **CB** | Castellated Beam | Beam with hexagonal web openings |
| **LB** | Cellular Beam (also: Litzka Beam) | Beam with circular web openings |
| **W-shape** | Wide-Flange Shape | Standard hot-rolled I-beam section |
| **WT-shape** | Structural Tee | T-section cut from W-shape |

## Axis and Reference Points

| Abbreviation | Full Term | Description |
|--------------|-----------|-------------|
| **ENA** | Elastic Neutral Axis | Axis of zero stress under elastic behavior |
| **PNA** | Plastic Neutral Axis | Axis dividing section into equal tension/compression areas |
| **CL** | Centerline | Center line of beam or opening |

## Failure Modes and Limit States

| Abbreviation | Full Term | Description |
|--------------|-----------|-------------|
| **LTB** | Lateral-Torsional Buckling | Out-of-plane buckling of compression flange |
| **FLB** | Flange Local Buckling | Local buckling of flange elements |
| **WLY** | Web Local Yielding | Yielding of web at concentrated loads |
| **WLC** | Web Local Crippling | Crushing failure of web at loads |
| **SWB** | Sidesway Web Buckling | Web buckling perpendicular to beam axis |

## Building Systems and Applications

## Design Factors and Coefficients

| Abbreviation | Full Term | Description |
|--------------|-----------|-------------|
| **φ** (phi) | Resistance Factor | LRFD reduction factor for strength |
| **φ_b** | Flexural Resistance Factor | φ for bending (typically 0.90) |
| **φ_c** | Compression Resistance Factor | φ for compression (typically 0.90) |
| **φ_t** | Tension Resistance Factor | φ for tension (typically 0.90) |
| **φ_v** | Shear Resistance Factor | φ for shear (0.90 or 1.00) |
| **Ω** (Omega) | Safety Factor | ASD factor of safety for strength |
| **Ω_b** | Flexural Safety Factor | Ω for bending (typically 1.67) |
| **Ω_c** | Compression Safety Factor | Ω for compression (typically 1.67) |
| **Ω_v** | Shear Safety Factor | Ω for shear (1.50 or 1.67) |
| **C_v** | Web Shear Coefficient | Reduction factor for web shear |
| **k_v** | Web Plate Buckling Coefficient | Coefficient for web buckling (1.2 or 5.34) |

## Notes

1. Abbreviations follow AISC standard notation conventions.
2. Greek symbols (φ, Ω, θ, λ, Δ) are defined in the symbols reference.
3. Subscript combinations (e.g., $M_{Vr}$, $V_{rh}$) combine base term with modifier.
4. Units: Imperial (kips, in., ksi) and SI (N, mm, MPa) both used in Design Guide.
5. LRFD and ASD methods use different subscripts: "u" for LRFD, "a" for ASD.
