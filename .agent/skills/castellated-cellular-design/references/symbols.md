# Symbols and Notation

This reference provides a comprehensive list of symbols used in castellated and cellular beam design per AISC Design Guide 31.

## Cross-Sectional Properties

| Symbol | Description | Units | Reference |
|--------|-------------|-------|-----------|
| $A$ | Cross-sectional area | in.² (mm²) | Chapter 3 |
| $A_c$ | Area of concrete in compression | in.² (mm²) | Composite design |
| $A_{net}$ | Combined area of top and bottom tees | in.² (mm²) | Section 3.2 |
| $A_{tee}$ | Area of tee section | in.² (mm²) | Section 3.2 |
| $A_{crit}$ | Sum of top and bottom areas at critical section | in.² (mm²) | Cellular beams |
| $A_{tee-crit}$ | Area of critical section (0.225D₀ from center) | in.² (mm²) | Cellular beams |
| $I_x$ | Moment of inertia about x-axis | in.⁴ (mm⁴) | All sections |
| $I_y$ | Moment of inertia about y-axis | in.⁴ (mm⁴) | All sections |
| $S_x$ | Elastic section modulus about x-axis | in.³ (mm³) | Flexure |
| $S_{x-tee}$ | Section modulus of tee about x-axis | in.³ (mm³) | Tee sections |
| $Z_x$ | Plastic section modulus about x-axis | in.³ (mm³) | Plastic analysis |

## Notes

1. All dimensions are in inches (mm) unless otherwise noted.
2. All forces are in kips (N) unless otherwise noted.
3. All moments are in kip-in. (N-mm) unless otherwise noted.
4. All stresses are in ksi (MPa) unless otherwise noted.
5. For castellated beams, unbraced length L = e.
6. For cellular beams, unbraced length L = D₀/2.
7. Web post length s = S - D₀ for cellular beams; s = 2e for castellated beams.
8. For 90% deflection factor, use 0.90·I_x per Section 3.7.
