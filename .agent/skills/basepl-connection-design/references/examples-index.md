## Usage Guide

**To find an example:**

1. **By load type**: Use the "Examples by Load Type" sections above
2. **By specific feature**: Use the "Search Keywords" section
3. **By page number**: Use the "Quick Reference Table"

**Workflow recommendations:**

- **Starting a new design**: Begin with the simplest applicable example
  - Pure compression → 4.7.1 or 4.7.3
  - Compression + moment → 4.7.9 (small) or 4.7.12 (large)
  - With shear → Add 4.7.4 (friction) or 4.7.5 (lug)

- **Checking specific limit states**: Find examples that demonstrate that check
  - Concrete bearing → 4.7.1, 4.7.2
  - Anchor breakout → 4.7.6, 4.7.8
  - Plate thickness → All examples
  - Shear transfer → 4.7.4, 4.7.5

- **Complex loading**: Build understanding progressively
  - Start: 4.7.1 (compression only)
  - Add moment: 4.7.9 or 4.7.12
  - Add shear: 4.7.11 or 4.7.12
  - Biaxial: 4.7.13, 4.7.14, or 4.7.15

## Notes on Example Format

All examples follow the standard format from Section 1.2.2:

1. **Problem Statement**: Given geometry, loads, materials
2. **Solution**: Step-by-step design calculations
3. **LRFD and ASD**: Parallel calculations shown side-by-side
4. **Checks**: Verification of all applicable limit states
5. **Summary**: Final design with selected components

**Key design outputs in each example:**
- Base plate dimensions (N × B)
- Base plate thickness (t_pl)
- Anchor rod quantity, diameter, and grade
- Weld sizes (column-to-plate)
- Additional elements (shear lugs, stiffeners, etc.)
